# Fallback park snapshot

`bucharest_parks_sectors.geojson` is the project's existing OpenStreetMap park cache from October 24, 2026 (167 source records, point locations and sector names).

The GitHub demo copies it only when no park cache has been restored. The collector attempts a live refresh and labels fallback use in the interface. This snapshot contains no air measurements or API credentials and does not provide polygon area or verified park entrances.
